Outputs

4. Implement correct planning behavior

Preserve separate fields for:
- Artifact state: draft / reviewed / adopted / superseded.
- Work state: Backlog / Ready / In progress / Review / Done,
  reconciled with the actual maintained workflow.
- Evidence maturity: unknown / designed / implemented / verified /
  qualified, for a named scope.

Track blocking as a separate condition. Do not replace the accepted
workflow with an invented set of statuses.

H blocks only the specified activity while its required output is unmet.
C represents coordination and must not create reciprocal whole-Plan
blocking. G applies to the relevant acceptance/activation gate.
O applies only under its stated condition and retains its H/C/G effect.

Unknown applicability or satisfaction must not silently count as met.
Avoid whole-Plan P05/P07 cycles by preserving contract versus integrated
acceptance distinctions.

An unmet prerequisite does not prevent defining a backlog task.
Assess drafting, implementation, qualification and release separately.

Calculate readiness indicators from applicable prerequisites, required
inputs, ownership and existing DoR. Keep work-state changes explicit.
Do not automatically mark a task Ready merely because blockers reach
zero, or Done because a PR merged.

Flag Done claims inconsistent with the task's actual acceptance.
Do not require qualified maturity where verified is sufficient.

Do not invent dates, estimates, capacity, deadlines or sprint commitments.
Provide editable fields for later approved inputs. Show overdue work
only where an actual due date exists. Unknown is not zero.
